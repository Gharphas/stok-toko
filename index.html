Buka Aplikasi di Handphone

Paling Praktis

Bisa dibuka langsung dari browser smartphone kapan saja tanpa menyalakan laptop terus-menerus.

  1. Buka Browser di Handphone (Google Chrome / Safari).
  2. Ketik URL GitHub Pages:
    *Di GitHub Repo → Settings → Pages → Source: pilih Branch main → Save.
  3. Tambahkan ke Layar Utama (Icon App di HP):

    🤖 Chrome Android: Tap titik tiga (⋮) → pilih "Tambahkan ke Layar Utama" / "Install Aplikasi".

    🍎 Safari iPhone: Tap tombol Share () → pilih "Add to Home Screen".

Jaringan Wi-Fi Sama

Akses langsung ke server di laptop saat HP dan laptop tersambung di Wi-Fi yang sama.

  1. Pastikan HP & Laptop terhubung ke Wi-Fi yang sama.
  2. Di laptop, jalankan server lokal:
    node serve.js
  3. Buka browser HP dan ketik: http://192.168.1.11:5500

Status Database & Backup

Mode Penyimpanan: Database Server (db.json)
Lokasi Database: stock-toko/data/db.json
Sinkronisasi HP & Laptop: Aktif & Real-time

Setiap barang masuk, barang keluar, dan stok baru langsung tersimpan otomatis ke file database di laptop. Data tersimpan permanen dan tidak akan berubah kecuali ada penginputan baru.
